# SMS Spam Detection Using Machine Learning

## Project Overview

This project is a Machine Learning-based SMS Spam Detection System.

It classifies text messages into two categories:
- Spam Message
- Not Spam Message

The system uses Natural Language Processing (NLP) techniques and a Naive Bayes algorithm to identify unwanted messages.

## Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Flask
- HTML
- CSS

## Machine Learning Algorithm

Multinomial Naive Bayes

## Dataset

SMS Spam Collection Dataset from UCI Machine Learning Repository.
